# Enclosure

The board is not shipped bare: it sits in a printed case behind the front panel
of the indoor unit.

## The case in use

**[Compact Enclosure for LILYGO T-CAN485 (RS485)](https://makerworld.com/de/models/2410211-compact-enclosure-for-lilygo-t-can485-rs485)**
by *LasseBang* on MakerWorld — a slim snap-fit shell with openings for USB-C
and the screw terminals, no screws needed.

The model is **not redistributed here**: it is published under MakerWorld's
Standard Digital File License, which does not permit that. Download it from the
link above.

## Print notes for this application

The designer's notes say PLA or PETG. For this installation that narrows:

| | |
|---|---|
| Material | **PETG or ASA — not PLA.** Behind the front panel it gets hotter in heating mode than PLA tolerates. PLA is fine for a fit test. |
| Layer height | 0.2 mm |
| Infill | 15–25 % |
| Supports | not required |
| Orientation | base flat on the bed |

## Placement inside the unit

* Behind the front panel, **out of the air path**.
* **Never above the condensate tray.** Water and electronics do not mix.
* Not against the heat exchanger.
* Secure the cable so it cannot reach the fan.
* Leave the unit's own IR receiver window clear, or the original remote stops
  working.
